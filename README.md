4. Nguyen V, Mathias R, Smith GD (2005)  
**A stochastic automata network descriptor for Markov chain models of instantaneously coupled intracellular Ca2+ channels.**  
*Bull Math Biol*, **67**(3):393-432.  

|          |                                                                |                                                          |                                                           |
|----------|----------------------------------------------------------------|----------------------------------------------------------|-----------------------------------------------------------|
| Abstract | [Abstract](http://www.springerlink.com/content/20345363770w6x78) | PDF                                                      | [PDF](http://www.springerlink.com/content/20345363770w6x78/fulltext.pdf) |
| Script   | [script](http://web.njit.edu/%7Ematveev/calc/examples/markov.par) |

The script [markov.par](http://web.njit.edu/%7Ematveev/calc/examples/markov.par) (linked above) demonstrates the use of  
[Markov variables](http://web.njit.edu/%7Ematveev/calc/manual.html#markov) to simulate stochastic Ca²⁺ channel gating, examining the coupling of two stochastic Ca²⁺ channels with 4-state gating kinetics by *Nguyen et al.* (2005).
